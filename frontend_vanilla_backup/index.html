System Architecture & Engineering Standards

This platform avoids unnecessary frameworks (no React, Next.js, TypeScript, Prisma, or ORMs) to ensure you understand every layer of software engineering. Every SQL query, API controller, and DOM event listener is fully readable, auditable, and defendable in technical assessments.

API Layer:
Express.js REST controllers with parameterization to eliminate SQL injection and standardized error payloads.

Pure HTML5 semantic elements, responsive CSS3 Grid & Variables, Vanilla JS ES6+ fetch controllers, and Chart.js.
